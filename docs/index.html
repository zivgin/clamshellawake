Free macOS menu-bar app

Keep your Mac awake with the lid closed.

ClamshellAwake keeps your MacBook running with the lid shut, no external monitor needed. Close the laptop, and your AI agents, builds, renders and downloads keep going.

Install from GitHub FAQ

What it does

Lid closed, still running

True clamshell mode without a display, keyboard or mouse attached.

Keep awake

Indefinitely or for a set time, with an option to keep the screen on.

Safety limits

Only on power, pause below a battery level, pause when hot. Always switched off on quit or crash.

CLI for scripts and agents

Control it from the terminal, so your scripts and coding agents can keep the Mac awake while they work.

Command line

clamshellawake                  # status
clamshellawake awake on 90      # keep awake for 90 minutes
clamshellawake lid on           # keep running with the lid closed
clamshellawake lid off && clamshellawake awake off

FAQ

How do I keep my MacBook awake with the lid closed?

Install ClamshellAwake and turn on Lid mode from the menu bar, or run clamshellawake lid on. The Mac keeps running with the lid shut, no external monitor, keyboard or mouse needed.

What is clamshell mode on a Mac?

Clamshell mode is Apple's name for running a MacBook with the lid closed. macOS normally allows it only with an external display and power connected. ClamshellAwake removes the external display requirement, safely and reversibly.

How is it different from caffeinate or Amphetamine?

They prevent idle sleep, but closing the lid still puts the Mac to sleep. ClamshellAwake keeps it awake and running with the lid closed, with battery, heat and time limits.

Is it safe to run a MacBook with the lid closed?

Yes, with limits. Run lid mode only on power, pause below a battery level or when hot, and it always switches off when the app quits or crashes. Keep the Mac on a hard, ventilated surface.

Why does it ask for my password once?

Lid mode uses pmset disablesleep. The first time, it installs a sudoers rule that allows only that one command, so after that it switches with no password.

Is it free?

Yes. Free and open source under the MIT license. No account, no tracking.
